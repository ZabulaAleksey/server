# Server — локальные инструкции

Перед началом работы прочитай `~/.codex/AGENTS.md`.

## Контекст проекта

- Небольшой сервер на Express 5 с точкой входа `server.js` и каталогом `public/` для раздаваемых ресурсов.
- Поддерживай явную проверку HTTP-ввода и границы файловой системы; никогда не раскрывай локальные секреты или произвольные файлы.
- Для локального запуска используй `node server.js` или существующий `start.bat`.
- Текущий скрипт `npm test` является намеренно падающей заглушкой; его нельзя представлять как успешно пройденный набор тестов.
- Не редактируй сгенерированные зависимости в `node_modules/`.

Загружай только относящиеся к задаче инструкции AI Dev Team; не загружай заранее все правила, файлы SPEC или `LEARNING_LOG.md`.


## Локальные правила тестирования

### Тестовый контракт
- После принятия тестов/fixtures/golden-сценариев они считаются контрактом; в этом цикле они только запускаются, а не меняются.
- Если фреймворк тестирования не описан в задаче — его нельзя игнорировать, его нужно добавить до финальной валидации.

### Unit / integration / component
- `npm test` сейчас является заглушкой с ошибкой и не считается выполненной автоматической проверкой.
- Для этого репозитория ввести и зафиксировать unit → integration → component после появления работающего тестового раннера.

### E2E
- Авто-E2E отсутствуют.
- Пока endpoint- и интеграционный контур не покрыт, использовать `BLOCKED_BY_BACKEND_SERVER`.
