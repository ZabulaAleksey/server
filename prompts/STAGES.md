# Этапы Server

## Этап 1 — HTTP quality baseline

Цель: добавить безопасные unit/integration проверки маршрутов, границы `public/` и корректные ошибки, не меняя контракт без отдельного решения.

DoD: тесты воспроизводимы локально, негативные path traversal сценарии покрыты, `AI_STATUS` содержит evidence.

## Этап 2 — endpoint smoke

Цель: добавить минимальный smoke-контур запуска сервера и проверки ключевых endpoint.

DoD: запуск/остановка изолированы, тесты не зависят от внешней сети, результаты сохранены в статусе.
